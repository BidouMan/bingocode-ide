# 引擎功能总览

一张表看完引擎已经实现的能力。很久没用某个功能、忘了它怎么用的时候，回到这里扫一眼，再去左侧「API 参考」查具体参数、返回值和完整示例。

<p class="home-note">说明：表里带「没有」「不做」字样的条目，是引擎<strong>当前还没实现</strong>的行为，写出来是为了提醒边界，避免误以为可以用。</p>

## 精灵 Sprite

| 功能 | 说明与用法 |
|------|-----------|
| `Sprite("名字")` | 创建一个角色，从 `assets/sprites/` 读取精灵包（`.bsf` / `.bgs`）或单张 PNG 图片 |
| `x` / `y` | 坐标，可读可写（用户坐标：地图左下角为原点，y 向上为正） |
| `pos` | 一次性读取 `(x, y)`，可直接拆包：`x, y = hero.pos`（只读） |
| `angle` | 朝向角度，可读可写（0=右 90=上 180=左 270=下） |
| `scale` | 大小百分比，默认 100，可读可写 |
| `layer` | 图层顺序，越大越靠前，可读可写 |
| `vy` | 垂直速度，正数向上、负数向下，可读可写 |
| `gravity` | 是否受地图重力影响，默认 True；设为 False 可做子弹、会飞的敌人 |
| `hitbox_scale` | 碰撞箱大小倍率，默认 1.0 |
| `delete()` | 彻底删除（画面、物理、内存、分组一起移除） |

## 移动与朝向

| 功能 | 说明与用法 |
|------|-----------|
| `goto(x, y)` | 传送到坐标；也接受另一个角色或标记引用：`goto(enemy)`、`goto(player.get_marker())` |
| `goto_rand()` | 随机传送到地图内某处 |
| `move(距离)` | 沿当前 `angle` 方向移动，长距离自动拆成小步、不会穿墙；**已按方向归一化**，走多快与朝向无关 |
| `add_x(n)` / `add_y(n)` | 分轴增减坐标（正数向右 / 向上）；**两轴同时用来做八方向移动时引擎不做归一化，斜着会快约 41%** |
| `set_x()` / `set_y()` / `set_xy()` | 直接设置坐标，只修正落点、不检查中间路径（可以穿过薄墙） |
| `set_angle(角度)` | 设置朝向 |
| `look_at(目标)` | 自动转向另一个角色或鼠标 |
| `set_speed(速度)` | 每帧自动沿当前方向移动，设为 0 停止（内部走 `move`，同样已归一化） |
| `edge_bounce()` | 碰到画面边缘自动反弹 |

## 跳跃与平台物理

| 功能 | 说明与用法 |
|------|-----------|
| `jump(力度)` | 基础跳：只给一个向上的速度，引擎**不判断是否在地面** → 在空中再次调用就是二段跳（可做多段跳）；**没有郊狼时间和跳跃缓冲** |
| `smart_jump(力度)` | 大小跳：按下起跳、按住跳得高、松手自动落下；必须写在 `if key_down(...)` 里；空中调用无效，做不了二段跳 |
| `stop_jump()` | 让正在上升的角色提前落下（上升重力 0.5 → 2.8）；自己不会起跳，主要给敌人 AI、撞天花板等场景用 |
| `drop_down()` | 站在「跳板」上时往下穿过去（放下后约 0.16 秒忽略跳板） |
| 自动重力与落地 | 地图开启「重力」后引擎每帧自动施加重力：上升 0.5、下落 1.1、松手截断 2.8，最大下落速度 10，落地自动清零 |
| 禁止下滑 | 地图属性，开启时站在斜坡上不会自动下滑（默认开启） |
| 禁用碰撞 | 角色可设为不参与重力和碰撞，但仍然能按代码移动、照常渲染 |

## 外观与动画

| 功能 | 说明与用法 |
|------|-----------|
| `show()` / `hide()` | 显示 / 隐藏（隐藏只是看不见，对象仍在内存里） |
| `say(文字, 秒数)` | 头顶气泡说话，新话替换旧话；秒数不填则永久显示，填秒数会自动消失 |
| `set_scale()` / `add_scale()` | 设置 / 增减大小（单位为百分比，`add_scale(10)` 是放大 10%） |
| `set_rotation_mode(方式)` | 旋转方式：`"all"` 自由旋转、`"left_right"` 只左右翻转、`"none"` 不旋转 |
| `play(动画名, 过渡秒数)` | 播放造型里的动画剪辑，如 `play("walk", 0.2)` |

## 标记与跟随

| 功能 | 说明与用法 |
|------|-----------|
| `get_marker(名字)` | 读取角色在编辑器「标记」图层标注的锚点（默认名「标记」，自动编号）；可给 `goto` / `follow` 用，也能读 `.x` / `.y` |
| `follow(目标, flip=True)` | 持续跟随另一个角色或标记（只跟位置，默认继承左右翻转，如父角色翻面武器跟着翻）；目标被删除会自动停止 |
| `unfollow()` | 停止跟随 |

## 键盘与鼠标

| 功能 | 说明与用法 |
|------|-----------|
| `key_down(key)` | 按键是否被按住（持续返回 True） |
| `key_pressed(key)` | 按键是否刚按下（只有那一次为 True） |
| `key_up(key)` | 按键是否刚松开 |
| `mouse_down()` | 鼠标是否被按住 |
| `mouse_pressed()` | 鼠标是否刚点击 |
| `mouse_up()` | 鼠标是否刚松开 |
| `mouse.x` / `mouse.y` / `mouse.pos` | 鼠标位置（游戏坐标，左下角为 0）；`mouse.pos` 可拆包 |

## 碰撞与感知

| 功能 | 说明与用法 |
|------|-----------|
| `is_touch(目标)` | 是否碰到另一个角色、鼠标、形状层标签或图块标签；贴边半像素内也算碰到 |
| `sweep_test(方向, 距离=2)` | 用身体朝一个方向扫一下，检查前方是否被挡住（只测试不移动；感应区不算；跳板仅向下且从上方靠近时算） |
| `is_on_wall()` | 本帧左右是否贴着墙 |
| `is_on_ceiling()` | 本帧头顶是否撞到东西（可配合 `stop_jump()`） |
| `raycast(方向, 距离)` / `hero.raycast(...)` | 从角色位置或任意点打一条射线，返回最近命中的实心地形 |
| `is_touch_group(组名)` | 碰到组内任意成员则返回那个成员，没碰到返回 None |
| `is_touch_edge()` | 视觉边缘是否碰到地图边界 |
| `is_out_screen()` | 是否整体完全离开游戏画面（飞出屏幕） |
| `is_on_ground()` | 是否真正站在地面（跳起、下落中、从下方穿过跳板都是 False） |
| `distance_to(目标)` | 到另一个角色或鼠标的像素距离 |

## 事件与分组

| 功能 | 说明与用法 |
|------|-----------|
| `add_to_group(组名)` | 把角色归到某个组，如 `"enemies"`、`"bullets"` |
| `on_touch_group(组名, 回调)` | 碰到组内成员时自动执行；不传回调则双方都删除，传回调则执行 `函数(自己, 对方)` |
| `on_sensor_enter(标签, 函数)` | 进入感应形状时执行一次，回调参数可写 0 / 1 / 2 个（角色, 标签） |
| `on_sensor_exit(标签, 函数)` | 离开感应形状时执行一次 |
| `broadcast(事件名)` | 发送全局广播，触发所有接收该事件的回调 |
| `receive(事件名)` | 这一帧有没有收到广播（入门写法，写在循环里） |
| `on_receive(事件名, 函数)` | 收到广播时执行自己的函数（进阶写法，注册一次、写在循环外） |

## 控制流程

| 功能 | 说明与用法 |
|------|-----------|
| `while True` / `run()` | 游戏主循环，每帧执行一次 |
| `pause()` / `resume()` / `is_paused()` | 暂停 / 继续 / 查询是否暂停（暂停时精灵停止移动） |
| `stop()` | 结束游戏，退出主循环 |
| `start_game()` / `register_generator()` | 生成器调度写法：自动发现并运行项目脚本（进阶） |
| `stop_game()` / `GameStop` | 生成器写法中抛出异常，中断当前生成器 |
| `wait(秒)` | 等待一段时间（生成器里用） |

## 时间

| 功能 | 说明与用法 |
|------|-----------|
| `time_passed(秒)` | 每隔几秒返回一次 True，用来做定时事件：`if time_passed(1): ...` |
| `Timer(秒, loop=True)` | 计时器对象，方法 `start()` / `stop()` / `is_timeout()`；用游戏时间，暂停游戏时会冻结 |

## 声音

| 功能 | 说明与用法 |
|------|-----------|
| `play_sound(名字, loop=False)` | 播放音效（`loop=True` 循环播放，可做背景音乐） |
| `stop_sound(名字)` | 停止音效；不传名字则停止全部音效 |

## 地图与相机

| 功能 | 说明与用法 |
|------|-----------|
| `load_map(名字)` | 加载并显示地图（`assets/maps/` 下的 `.bgm` 地图包） |
| `map.get_marker(名字)` / `map.get_markers(类型)` | 读取地图编辑器里放的标记；找不到返回 None |
| `map.is_solid(x, y)` | 某个用户坐标点是否实心（感应不算；跳板算） |
| `camera_follow(角色)` | 镜头跟随指定角色 |

## 工具函数

| 功能 | 说明与用法 |
|------|-----------|
| `show_text(x, y, 内容...)` | 在屏幕指定位置显示文字，多个参数自动拼接 |
| `shake(强度, 时长)` | 屏幕震动效果 |
| `show_fps(显示)` | 显示 / 隐藏帧率 |
| `show_collision(角色)` | 显示角色的碰撞箱可视化 |
| `random_int()` / `random_float()` | 取随机整数 / 随机小数 |

## 地图碰撞特性

| 功能 | 说明与用法 |
|------|-----------|
| 墙体 / 跳板 | 图块和图像的碰撞类型：**墙体**四面阻挡；**跳板**是单向平台，可从下方穿上去 |
| 斜坡 | 可以站立并顺着走；是否自动下滑由地图属性「禁止下滑」控制 |
| 多边形碰撞 | 图像实例可用多边形做精确碰撞，凹多边形会自动三角剖分 |
| 世界边界 | 角色被限制在地图范围内，越界会被拉回 |
