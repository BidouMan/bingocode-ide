# 角色编辑器

角色编辑器用于创建和编辑游戏角色（精灵）。

## 打开角色编辑器

1. 确保在「游戏模式」下
2. **双击**已经创建的角色图标
3. 页面会跳转到角色编辑器页面

## 角色包（.bgs）

BingoCodeIDE 使用 `.bgs` 格式的角色包文件。一个角色包包含：

- **config.json**：角色配置文件
- **PNG 图片**：角色的每一帧图片

### 选择角色

BingoCodeIDE 提供了丰富的内置角色：

1. 在资源面板点击「选择角色」按钮
2. 浏览可用的角色
3. 点击角色即可添加到项目中

### 绘制角色

BingoCodeIDE 提供了丰富的内置角色：

1. 在资源面板点击「绘制角色」按钮
2. 进入角色绘制页面
3. 用户可以自己绘制角色的每一帧图片
4. 点击「保存」按钮保存角色

### 上传角色

1. 在资源面板点击「角色」标签
2. 点击「上传角色」按钮
3. 在本地文件夹中选择一张或多张 PNG 图片
4. 点击确定即可完成上传

## 帧动画

帧动画是通过快速切换多张图片来实现的动画效果。

### 添加动画帧

1. 在角色编辑器中打开角色
2. 选定指定帧数设为动画帧
3. 修改动画名称
4. 修改帧速率

<!-- screenshot: editor/animation-frames.png -->
<!-- alt: 动画帧编辑 -->
<!-- description: 显示动画帧列表和预览 -->

### 设置帧速率

帧速率控制动画播放速度：

- **每帧时间**：每张图片显示的秒数
- 默认值：0.1 秒（每秒 10 帧）
- 值越小，动画越快
- 这个速率最终会影响到游戏运行时角色动画的播放速度

### 动画命名

为动画命名以便在代码中调用：

```python
# 播放名为 "walk" 的动画
player.play("walk")
```

## 碰撞框

碰撞框决定了角色的碰撞检测范围。

### 查看碰撞框

1. 在角色编辑器中打开角色
2. 点击「碰撞」按钮
3. 碰撞框会以半透明颜色显示

### 调整碰撞框

- 拖动边缘调整大小
- 拖动中心调整位置
- 可以根据需求调整或创建不同形状的碰撞框
- 我们也可以给角色禁用它的碰撞

## 角色中心点

1. 默认角色中心点都在角色中心位置
2. 可以根据需求手动调整角色中心点的位置
3. 点击「中心」按钮即可移动角色中心点
4. 中心点会直接影响角色的旋转中心,所以要小心调整

## 属性设置

### 基本属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 名称 | 角色在代码中的名字 | 必填 |
| 大小 | 初始缩放百分比 | 100 |
| 朝向 | 初始角度 | 0 |
| 图层 | 渲染顺序（越大越靠前） | 0 |

### 旋转模式

| 模式 | 说明 |
|------|------|
| 自由旋转 | 角色可以任意角度旋转 |
| 左右翻转 | 只水平翻转，不旋转图片 |
| 不旋转 | 完全不旋转 |

## 常见问题

### Q: 角色导入后显示不正常？

1. 检查图片格式是否正确
2. 确认角色尺寸适合合适
3. 检查角色是否有缺失的图片帧

### Q: 动画播放问题？

1. 调整帧速率设置。每帧时间越短，动画越快。
2. 设置动画名称后,代码中的动画名是否一致

### Q: 碰撞检测不准确？

1. 检查碰撞框是否正确
2. 检查碰撞功能是否被禁用
3. 检查中心点是否正确设置
