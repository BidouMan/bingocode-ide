# 第一个游戏

这一页带你做出第一个能玩的小作品：**用方向键控制角色在舞台上走动，碰到金币就让金币换个位置**。

不需要先学 Python。代码只有二十来行，我们一步一步往里加，每一步都能运行看到效果。

<!-- screenshot: getting-started/first-game-preview.png | 完成后的效果：方向键控制角色移动，碰到金币后金币换位置 -->

## 先看一眼界面

<!-- screenshot: getting-started/main-interface.png | 启动后的界面：左边是预览和资源列表，右边是代码编辑器 -->

- **顶部菜单栏**：「项目」管新建 / 打开 / 保存，「代码 / 角色 / 地图」切换编辑器，「设置」调整选项
- **左侧上部**：游戏预览画面，运行后游戏就显示在这里
- **左侧下部**：资源列表，分「角色 / 场景 / 声音 / 代码」四个页签
- **右侧**：代码编辑器，写游戏逻辑的地方
- **预览上方**：▶ 运行、■ 停止
- **底部**：控制台，程序出错时会在这里提示原因

> 右上角的开关能在「游戏模式」和「代码模式」之间切换。本教程一直待在**游戏模式**，只有它才显示预览画面。

## 第 1 步：直接开始写

应用每次启动都是一个干净的新项目：右侧已经打开一个空的 `游戏脚本_1.py`，左边资源列表是空的。

我们可以直接从这里开始制作,每次新建项目都要养成**保存**的习惯。

> 如果想把项目彻底清空重来，用菜单「**新建项目**」。它会删掉默认项目里已有的角色、地图、声音和代码；想留着就先「**保存项目**」。

## 第 2 步：添加两个角色

先加主角，再加一个金币。

1. 确认资源列表停在「角色」页签
2. 在下方的菜单栏中选择「**选择角色**」
3. 从内置资源库中选择一个角色导入项目

然后再重复一次，导入第二个角色当金币。

导入后名字是自动编号的：第一个叫 `角色1`，第二个叫 `角色2`,我们可以根据需要修改名字。
**代码里写的名字必须和这里完全一致**。

<!-- screenshot: getting-started/first-game-sprites.png | 内置资源库中有分类标签,金币在「道具」分类下 -->

> 想用自己的图片，就在抽屉里点「**上传角色**」；想亲手画一个，点「**绘制角色**」。

## 第 3 步：添加地图
1. 确认资源列表停在「场景」页签
2. 点击选择地图按钮
3. 在内置资源库中选择一张背景图
<!-- screenshot: getting-started/first-game-map.png | 导入地图后，资源面板里显示 地图 -->

## 第 4 步：让角色跟着方向键动

在右侧编辑器里写下这段代码：

```python
# 创建地图
map = load_map('地图')

# 创建角色
player = Sprite("小黄鸡")

# 游戏循环
while True:
    if key_down("left"):
        player.add_x(-5)
    if key_down("right"):
        player.add_x(5)
    if key_down("up"):
        player.add_y(5)
    if key_down("down"):
        player.add_y(-5)
```

然后运行：

1. 点预览左上方的 ▶
2. 运行后会显示角色和地图
3. 按方向键，角色就会动起来

<!-- screenshot: getting-started/first-game-map-run-01.png | 游戏窗口可以放大全屏显示 -->
> 如果程序运行出错,请仔细检查代码是否正确。

## 第 5 步：走路时自动转身

现在角色只会平移。先在循环外开启「左右翻转」模式：

```python
player.set_rotation_mode("left_right")
```

再把循环里控制左右移动的两段改成这样：

```python
    if key_down("left"):
        player.add_x(-5)
        player.set_angle(180)   # 朝左
    if key_down("right"):
        player.add_x(5)
        player.set_angle(0)     # 朝右
```

`left_right` 模式下，角色旋转方式会转换为左右翻转模式，`0` 是朝右，`180` 是朝左。

## 第 6 步：加上金币

在 `player = Sprite("小黄鸡")` 下面、`while True` **外面**，创建金币并把它放到右上角：

```python
coin = Sprite("金币")
coin.goto(480, 360)   # x 向右，y 向上
```

然后在 `while True` 里面，和前面几个 `if` 并列，加上碰撞判断：

```python
    if coin.is_touch(player):
        coin.goto_rand()
```

`is_touch(player)` 判断两个角色的碰撞框有没有重叠；`goto_rand()` 把金币随机放到舞台上的某个位置。

按下方向键追到金币，它就跳走了——已经是个小游戏了。

## 完整代码

把前面几步合起来，就是最终版本，可以直接整段复制：

```python
# 创建地图
map = load_map('地图')

# 创建角色
player = Sprite("小黄鸡")
player.set_rotation_mode('left_right')  # 设置翻转模式

# 创建金币
coin = Sprite('金币')
coin.goto(480,360)

# 游戏循环
while True:
    # 角色左右移动
    if key_down("left"):
        hero.set_angle(180) # 朝右
        player.add_x(-5)
    if key_down("right"):
        hero.set_angle(0)   #朝左
        player.add_x(5)

    # 角色上下移动
    if key_down("up"):
        player.add_y(5)
    if key_down("down"):
        player.add_y(-5)
    
    # 金币检测碰到玩家后,移到随机位置
    if coin.is_touch(player):
        coin.goto_rand()

```

## 这段代码是怎么跑起来的

**`while True` 是游戏主循环。** 在循环中的代码大约每秒执行 60 次。
所以 `add_x(5)` 不是「移动一次 5 像素」，而是「每一帧移动 5 像素」，一秒大约移动 300 像素。

**坐标原点在舞台左下角。** x 向右变大，y 向上变大，舞台固定 640 × 480，角色出生在正中央 `(320, 240)`。

**`Sprite(...)` 和 `goto(...)` 写在循环外面。** 它们只需要执行一次。
如果把 `Sprite("小黄鸡")` 放进 `while True`，每一帧都会新建一个角色，很快就会乱掉。

**`key_down` 是检测用户按键的。**

**`Sprite("小黄鸡")` 里的名字就是资源面板里显示的名字**，我们可以自己修改名字。

## 动手改一改

跑通之后，试着改几个数字，看看有什么变化：

- 把 `add_x(5)` 里的 `5` 改成 `10`，角色走得更快
- 把 `coin.goto_rand()` 换成 `coin.goto(100, 100)`，金币固定跑到左下角附近
- 在 `while True` 外面加一行 `hero.say("你好")`，让角色开口说话
- 把 `if key_down("up")` 换成 `if key_pressed("up")`，看看按一下只动一步是什么感觉

## 常见问题

### 角色不显示

- 看底部控制台，如果出现 `[警告] 角色 '小黄鸡' 不存在，请先在资源管理器中添加`，并修改角色名称
- 确认角色确实已经导入到「角色」列表

### 按键没反应

- 先用鼠标点一下预览画面，再按方向键
- 确认游戏正在运行（▶ 处于激活状态）
- 如果改过代码，记得先 ■ 停止再 ▶ 运行

### 点了 ▶ 没反应

- 如果代码还是空的，运行后会立刻结束，看起来像「没反应」——先写几行再看
- 代码有语法错误时，底部控制台会显示红色报错，按提示的行号修改

### 金币不见了

- 确认第二个角色已经导入，并且代码里写的是它的名字
- `goto_rand()` 会把金币放到舞台上任意位置，可能正好被主角挡住，走两步找找看
