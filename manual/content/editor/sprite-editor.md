角色编辑器负责把一张图片变成可以旋转、碰撞、播放动画、挂接武器的游戏角色。代码里的 `Sprite` 只是读取这里保存好的数据。

## 界面总览

<figure class="shot" data-file="sprite-editor-overview.png" data-caption="角色编辑器总览：造型列表、画布、标注图层和右侧属性" data-desc="建议截取角色编辑器完整界面，包含左侧造型列表、中间画布、顶部工具栏和右侧属性/动画面板；不要加标注。"></figure>

| 区域 | 作用 |
|------|------|
| 左侧造型列表 | 管理角色的每一帧图片，选中哪一帧，画布就显示哪一帧 |
| 中间画布 | 预览造型，放置中心点、碰撞体和标记 |
| 顶部工具栏 | 中心点 / 碰撞 / 标记三个标注图层，以及画笔、缩放等工具 |
| 右侧面板 | 当前标注的属性、坐标、作用域；下方是动画片段列表 |

## 造型与动画

### 造型：角色的一帧

一个造型就是一张图片。角色可以只有一个造型，也可以有很多个造型。

- 列表顶部的造型是默认造型；没有播放动画时，引擎显示选中的默认造型。
- 拖动造型可以调整顺序；动画片段按造型的位置区间读取帧。
- 支持从本地添加图片、从内置素材库选帧，或直接在绘制页画一张新图。

### 动画片段：把造型串起来

动画片段是一段有名字的造型序列。给片段设置名称、起始帧、结束帧、帧率和是否循环。

| 设置 | 说明 |
|------|------|
| 名称 | 代码里 `play()` 使用的名字，例如 `idle`、`walk`、`attack` |
| 起始 / 结束 | 片段使用哪几帧；可以重复使用同一帧 |
| 帧率 | 每秒播放多少帧；每个片段可以单独设置 |
| 循环 | 开启后播到最后一帧会回到开头；关闭则停在最后一帧 |

```python
hero.play("idle")

while True:
    if key_down("left") or key_down("right"):
        hero.play("walk")
    else:
        hero.play("idle")
```

> **注意：** 动画只改变角色显示哪一帧，不会自动移动角色。移动仍然要用 `add_x()`、`move()` 或 `set_speed()`。

## 标注三大件：中心点、碰撞、标记

  <p>中心点决定角色“以哪里为位置和旋转中心”；碰撞决定“哪里会挡住墙”；标记决定“武器和挂件挂在哪里”。</p>
</div>

<figure class="shot" data-file="sprite-editor-annotate.png" data-caption="画布上的中心点十字、碰撞框和标记图钉，以及顶部三个标注图层按钮" data-desc="建议截取角色编辑器的画布和标注工具栏，能清楚看到中心点十字、碰撞框、标记图钉，以及「中心点 / 碰撞 / 标记」三个按钮。"></figure>

### 中心点：角色的位置和旋转支点

中心点是角色的“轴心”。引擎里的 `hero.x`、`hero.y` 记录的就是中心点的位置，角色旋转、`look_at()` 瞄准也都围绕它进行。

- 默认中心点通常在图片内容框的中心附近。
- 拖动中心点会改变角色的旋转支点，也会改变角色贴图相对坐标的偏移。
- 中心点明显偏离内容中心时，旋转起来会有“甩出去”的感觉；武器挂点也会跟着变化。
- 「恢复统一」把中心点恢复到打开编辑器时的初始值；「仅当前帧」可以只给某一帧设置不同的中心点。

> **提示：** 只有 `.bsf` 角色能保存中心点。单张图片角色第一次保存标注时，会自动转成 `.bsf` 目录；原来的图片会变成 `sheet.png`，资源路径和缩略图会自动同步。

### 碰撞：决定角色怎样撞墙

碰撞体是角色参与地形碰撞的范围。默认使用“自动碰撞”，也就是图片非透明内容的包围盒。

| 操作 | 效果 |
|------|------|
| 自动 | 删除自定义碰撞，回到内容包围盒；适合大多数角色 |
| 矩形 | 用矩形框住角色；适合方块、箱子、简单角色 |
| 多边形 | 用自定义多边形贴合角色轮廓；适合斜坡、复杂形状 |
| 禁用碰撞 | 角色不再参与地形和边界阻挡；常用于纯装饰、特效、UI |

- 拖动画布上的手柄可以调整碰撞范围；从“自动”开始拖动时，会立即转成自定义矩形。
- 碰撞范围会跟随 `scale` 一起缩放；角色放大后，碰撞体也会变大。
- 可以给某一帧单独设置碰撞，例如角色蹲下时碰撞体变矮。
- 想确认实际碰撞范围，可以在代码里调用 `show_collision(hero)`。

> **注意：** 这里的碰撞只决定角色和地形、边界的关系。角色和角色之间的碰撞检测由 `is_touch()`、`is_touch_group()` 负责，用的是同一套碰撞范围。

### 标记：给武器和挂件一个位置

标记是角色身上的命名锚点，用来挂接武器、特效、血条等对象。代码里通过 `get_marker()` 读取。

- 点击「添加」创建标记，默认名字是 `标记`、`标记1`、`标记2`……
- 标记名可以改成 `手`、`枪口`、`头顶` 这样的语义化名字。
- 可以给某一帧单独调整标记位置，例如挥手时手的位置变化。
- 标记会跟随角色的位置、旋转、缩放和左右翻转实时变化。

```python
hero = Sprite("玩家")

# 把武器放到“手”的标记上，并持续跟随
gun = Sprite("木剑")
gun.follow(hero.get_marker("手"))

# 也可以只瞬移一次
effect = Sprite("特效")
effect.goto(hero.get_marker("枪口"))
```

> **提示：** 标记名写错时，`get_marker()` 会返回 `None`，并在控制台列出这个角色已有的标记名。

## 保存与资源格式

- 角色编辑器的修改会自动保存，不需要手动点保存。
- `.bsf` 是当前的推荐格式：一个目录里包含 `manifest.json` 和 `sheet.png`，中心点、碰撞、标记、动画都写在 `manifest.json` 里。
- 旧的 `.bgs` 格式仍然可以打开和使用，但新角色建议统一用 `.bsf`。
- 单张图片角色也可以直接使用；第一次保存中心点、碰撞或标记时，会自动转成 `.bsf`。
- 同一个角色不要在多处重复维护副本；资源面板里的角色就是项目里的唯一来源。

## 检查清单

做完一个角色后，按顺序检查这几项：

- 造型顺序正确，默认造型是希望静止时显示的那一帧。
- 动画片段名称和代码里的 `play()` 完全一致。
- 中心点在角色重心附近，旋转时不会明显偏移。
- 碰撞范围贴合角色，不会出现“看起来没碰到却撞墙”的情况。
- 需要挂武器的角色，标记名称和代码里的 `get_marker()` 完全一致。
